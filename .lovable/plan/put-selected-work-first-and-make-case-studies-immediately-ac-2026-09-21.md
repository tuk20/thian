# Put selected work first and make case studies immediately accessible

## Goal
Make the portfolio useful to a hiring manager within the first screen: show the beginning of the work section immediately and let every project open its case study with one click.

## Homepage structure
1. Keep a shorter introduction with Thian Uk, “UX Designer,” core specialties, and a clear “View selected work” link.
2. Move **Selected Works** directly below the introduction, before About Me and Design Philosophy.
3. Size the introduction so the Selected Works heading and start of the first project are visible at the bottom of a typical desktop screen.
4. Keep About Me, Design Philosophy, Contact, and the footer below the projects.
5. Reorder the main navigation to lead with Works while preserving the existing section links and mobile menu.

## Project presentation
Replace the desktop-only eyelid/hover reveal with responsive editorial rows:

- A large, always-visible project image
- Project title and industry
- A concise description of the work and its outcome
- Timeline and a clear arrow affordance
- The entire row opens the case study directly in one click
- Subtle image movement and color feedback on hover/focus, without hiding information
- A stacked version on mobile with the same visible information and direct link

CBANA remains first, followed by Mind Over Matter, NAIC, and Kater.it.

## Interaction and accessibility
- Preserve keyboard focus and descriptive project labels.
- Remove hover-dependent content so touch, keyboard, and desktop visitors receive the same essential information.
- Respect reduced-motion settings for the remaining transitions.
- Keep the existing nature-inspired green visual system and typography.

## Validation
- Check desktop and mobile layouts for text fit, image clarity, and section order.
- Confirm the first project is visible or clearly beginning within the initial desktop viewport.
- Open each project from its homepage row and confirm it reaches the correct case study in one click.
- Confirm navigation still scrolls correctly to Works, About, Philosophy, and Contact.
